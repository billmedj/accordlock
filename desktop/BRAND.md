# AccordLock Brand

AccordLock is the verified handoff between human intent and autonomous execution. Its identity should feel precise, calm, and operational.

## Mark

The Accord mark shows two paths meeting at one controlled transaction point. It represents a mandate and an action becoming bound before execution.

- Use the supplied artwork without redrawing or rotating it.
- Keep at least one center-node width of clear space around the mark.
- Use the standalone mark at 16 px or larger. Use the wordmark when AccordLock is not already named nearby.
- Do not replace the mark with a shield, padlock, key, or checkmark.
- Do not use approval, warning, or denial colors in the masterbrand. Those colors belong to product state.

## Palette

| Role         | Color                          | Hex       |
| ------------ | ------------------------------ | --------- |
| Ink          | Near-black foundation          | `#111318` |
| Slate        | Secondary structure            | `#7E8492` |
| Paper        | Primary path and light surface | `#F4F1E9` |
| Signal       | Transaction point              | `#5264E8` |
| Signal light | Signal highlight               | `#8491FF` |

The mark may appear in full color on Ink, or as a single-color mark when a platform requires a template asset. Keep success green, warning amber, and denial red reserved for their literal interface meanings.

## Wordmark and copy

Write the product name as **AccordLock**. Do not abbreviate it in customer-facing copy. Use sentence case, short labels, and concrete verbs. Avoid security theater, exaggerated claims, and unexplained internal terminology.

## Assets

The desktop icon family is generated by `ui/desktop/scripts/generate-accordlock-icons.mjs`. Run the following from `ui/desktop` after changing its vector definition:

```sh
pnpm run brand:icons
```

Do not edit generated PNG, ICO, or ICNS files by hand.
