# AccordLock support

AccordLock is currently distributed as an open-source technical preview.
Community support is best-effort and does not include a service-level agreement,
warranty, production on-call response, or security certification.

## Where to ask

- **Usage question or design discussion:** use GitHub Discussions when enabled.
- **Reproducible defect:** open a bug report using the issue template.
- **Feature proposal:** open a feature request and describe the concrete workflow
  and security outcome.
- **Documentation problem:** open an issue with the exact page and proposed
  correction.
- **Security vulnerability:** follow [SECURITY.md](SECURITY.md). Never publish
  exploit details, credentials, or customer information in an issue.
- **Conduct or trademark matter:** request a private contact channel as described
  in the relevant policy.

Before requesting help, search existing issues, use the pinned tool versions,
and capture the smallest reproducible example. Include the AccordLock version or
commit, operating system, command, expected result, actual result, and sanitized
logs.

## Supported environments

Only environments explicitly exercised by the continuous-integration workflows
and the latest release notes are considered tested. A test passing in a local or
synthetic environment does not imply production support for a cloud, Kubernetes
distribution, identity system, or deployment topology.

## Commercial and production support

No commercial support channel is offered through this repository at present.
When a supported pilot or commercial offering exists, its scope, response times,
security responsibilities, and deployment boundary will be defined in a separate
written agreement. Community channels must not be used to share customer data or
confidential configuration.
