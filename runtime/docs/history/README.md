# Historical engineering records

These files preserve dated internal validation and design records from before
the AccordLock public-release cleanup.

They are included for transparency only:

- product and identifier names were normalized during the pre-release rebrand;
- their recorded commands, file counts, hashes, and results apply only to the
  source snapshot that existed on the date shown;
- they have not been rerun against the current tree; and
- they are not current assurance, benchmarks, or independent review.

Use the current [documentation index](../README.md),
[known limitations](../KNOWN_LIMITATIONS.md), and the newest release validation
report when evaluating AccordLock.
